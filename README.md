# sistemRICAL

Prototipo de escritorio web inspirado en interfaces de sistemas operativos modernos y plataformas gaming.

## Ejecutar

Abre `index.html` en un navegador moderno. Para publicar gratis con GitHub Pages, entra en **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda. Luego GitHub mostrará la URL publicada en esa misma sección.

## Incluye

- Escritorio con barra de tareas y menú de aplicaciones.
- Ventanas que se pueden minimizar, maximizar y cerrar.
- Explorador de archivos de demostración.
- Configuración con controles interactivos.
- Terminal de demostración con comandos `help`, `date`, `system`, `store`, `settings`, `clear` y `reboot`.
- Panel de búsqueda y centro de control.
- Espacio inicial para la futura sistemRICAL Store.

## Nota

Esto es una interfaz web simulada, no un sistema operativo de bajo nivel como Windows. Las funciones de archivos, red, actualizaciones y tienda real necesitan integraciones adicionales. No se procesan pagos ni se instalan juegos en esta versión.
